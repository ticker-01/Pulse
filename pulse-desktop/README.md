# МГКАП · Pulse — десктопная версия на Rust

Кроссплатформенный клиент расписания колледжа: **Windows, Linux, macOS**.
Ядро (загрузка PDF, парсинг, звонки, аналитика) вынесено в `pulse-core` и покрыто
тестами; интерфейс — `pulse-app` на [`egui`/`eframe`](https://github.com/emilk/egui).

Почему Rust и как это соотносится с Android-версией — в
[`../docs/PULSE_DESKTOP_RUST.md`](../docs/PULSE_DESKTOP_RUST.md).

## Сборка и запуск

Нужен Rust 1.85+ (проверено на 1.100) и системные библиотеки для оконного ввода:

```bash
# Linux (Debian/Ubuntu): оконный ввод и OpenGL
sudo apt install build-essential pkg-config libxkbcommon-dev libwayland-dev \
                 libx11-dev libxcursor-dev libxi-dev libxrandr-dev libgl1-mesa-dev
```

```bash
cd pulse-desktop
cargo run -p pulse-app                  # отладочная сборка
cargo build --release -p pulse-app      # бинарник: target/release/pulse-app
cargo test --workspace                  # 60 тестов ядра + 4 теста интерфейса
```

На Windows и macOS ничего дополнительно ставить не нужно: `eframe` тянет
winit/glow, а системный шрифт для кириллицы подхватывается автоматически.

### Иконки и шрифты

Иконки в интерфейсе — обычные символы Unicode. Встроенный в `egui` шрифт
Ubuntu-Light эмодзи не содержит, поэтому включена фича `egui/monochrome_emoji_fonts`:
в сборку попадают NotoEmoji и emoji-icon-font, и иконки рисуются одинаково
на всех трёх ОС. Символы, которых нет ни в одном из этих шрифтов, заменены
на похожие по смыслу (например, пробирка 🧪 → атом ⚛).

Проверяется тестом `every_used_icon_has_a_glyph`: он рендерит все иконки
приложения с политикой `MissingGlyphPolicy::Panic`, поэтому новый символ без
глифа уронит `cargo test`, а не превратится в «квадратик» у пользователя.

### Скриншоты вкладок без окна

```bash
cargo test -p pulse-app --features shots render_tabs_to_png -- --ignored --nocapture
```

Кладёт PNG в `/tmp/pulse-shots` (тёмная и светлая темы, неделя, диалог, редактор
звонков). Фича `shots` тянет wgpu, поэтому по умолчанию не собирается.

## Где лежат данные

Один каталог, JSON-файлы с теми же именами полей, что в Android-версии:

| ОС | Каталог |
|---|---|
| Linux | `~/.local/share/pulse` |
| macOS | `~/Library/Application Support/by.Pulse.pulse` |
| Windows | `%APPDATA%\Pulse\pulse\data` |

Файлы: `settings.json`, `schedule.json`, `teachers.json`, `homework.json`,
`performance.json`, `bells.json`, `last_raw_text.txt`. Путь всегда виден
в строке состояния и в «Настройки → Данные».

Переносимый режим (флешка, тесты, второй профиль):

```bash
PULSE_DATA_DIR=/путь/к/каталогу cargo run -p pulse-app
```

## Что умеет

| Вкладка | Возможности |
|---|---|
| Расписание | День/неделя, навигация по датам, блок «сейчас и далее», звонки дня, подсветка текущей пары |
| Преподаватели | Справочник из расписания, поиск по фамилии/предмету/кабинету, личное расписание по дням |
| Успеваемость | Семестры, предметы, оценки и КР, средний балл, стипендия, распределение, риски, тренды, рекомендации, симуляция «что будет, если» |
| Домашние задания | CRUD, сроки, «осталось пар», напоминание накануне, группы «просрочено / сегодня / далее» |
| Уведомления | Сводка внутри окна: просроченные ДЗ, сроки, пары на сегодня и завтра, долги, предметы без оценок |
| Настройки | Имя и группа, тёмная/светлая тема, 10 акцентных цветов, режим округления, автообновление, редактор звонков, сокращённые дни, сброс данных |

Обновление расписания — кнопка «⟳ Обновить»: приложение скачивает страницу с
сайта колледжа, находит PDF, извлекает текст и разбирает пары. Всё в фоновом
потоке, интерфейс не блокируется.

## Ограничения (осознанные)

1. **Системных уведомлений ОС нет.** Вкладка «Уведомления» — внутренний центр
   напоминаний: сводка собирается при открытии, пока приложение запущено.
   Планировщик задач ОС и трей не реализованы.
2. **Нужна сеть для обновления расписания.** Офлайн приложение работает на
   кэше `last_raw_text.txt` и `schedule.json`.
3. **Нет NFC/QR-обмена, виджетов и Wear OS** — это мобильные особенности,
   десктопного аналога у них нет.
4. **Разбор PDF зависит от структуры файла.** Если сайт поменяет вёрстку или
   отдаст скан без текстового слоя, парсер не найдёт пары — причина будет
   видна в журнале загрузки (stderr) и в строке состояния.

## Структура

```
pulse-desktop/
├── Cargo.toml                 # workspace: pulse-core + pulse-app
└── crates/
    ├── pulse-core/            # логика без GUI, 60 тестов
    │   └── src/
    │       ├── model.rs       # LessonPair, Teacher, кэш расписания
    │       ├── parser.rs      # разбор текста расписания, группы, преподаватели
    │       ├── bells.rs       # звонки: обычный/понедельник/четверг/суббота/сокращённый
    │       ├── source.rs      # страница колледжа → PDF → текст
    │       ├── homework.rs    # домашние задания, «осталось пар»
    │       ├── performance.rs # предметы, семестры, округление, средние
    │       ├── analytics.rs   # стипендия, риски, тренды, симуляция
    │       ├── subject_theme.rs # эмодзи и цвет по названию предмета
    │       ├── datetime.rs    # разбор и «человеческое» форматирование дат
    │       └── storage.rs     # атомарная запись JSON в каталог данных
    └── pulse-app/             # egui/eframe
        └── src/
            ├── main.rs        # окно 1200×800, минимум 960×620
            ├── app.rs         # состояние, вкладки, фоновое обновление, окна
            ├── store.rs       # настройки и файлы
            ├── theme.rs       # палитра, шрифты
            └── views/         # по модулю на вкладку + общие элементы
```

Тесты интерфейса (`pulse-app`) считают раскладку без окна через
`egui::Context::run_ui`: каждая вкладка, пустое состояние, открытые диалоги и
сброс данных проверяются обычным `cargo test`. Отдельный тест проверяет,
что у каждой иконки есть глиф в подключённых шрифтах.
